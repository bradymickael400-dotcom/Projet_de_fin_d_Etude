\subsection{Dictionnaire exhaustif du schéma relationnel actif}
\label{subsec-dictionnaire-schema-actif}

Le présent dictionnaire est issu du catalogue PostgreSQL effectivement déployé dans le schéma \code{argos}. Il recense exactement \textbf{48 tables et 559 colonnes}. Les mentions \textbf{PK}, \textbf{FK}, \textbf{UQ} et \textbf{NN} désignent respectivement une clé primaire, une clé étrangère matérialisée, une unicité matérialisée et une colonne non nulle. Une \emph{relation logique} est exploitée par le code applicatif, mais n'est pas imposée par une contrainte de clé étrangère dans la base. Les types sont ceux retournés par \code{format\_type} dans le catalogue PostgreSQL; les colonnes de type \code{serial} ou \code{bigserial} y apparaissent donc comme \code{integer} ou \code{bigint}.
