# Corpus documentaire ARGOS

Déposez ici uniquement des documents que l'organisation est autorisée à utiliser
(`.md`, `.txt` ou `.rst`). Le moteur RAG lit le contenu local, conserve le chemin
et les lignes comme provenance, et n'invente pas de corpus. Aucun texte
réglementaire n'est fourni dans ce dépôt. Enregistrer pour chaque document son
autorité, sa juridiction, sa version, sa date de vérification et ses conditions
d'utilisation dans le document lui-même ou dans un manifeste associé.
